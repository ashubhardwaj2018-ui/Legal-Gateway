Module 1 – Team Users & Access Management
Create a complete User Management module.
Admin should be able to:
•	Create new users 
•	Edit users 
•	Deactivate users 
•	Delete users 
•	Reset passwords 
•	Unlock accounts 
•	Force password change 
•	View login history 
•	View activity logs 
•	View last login 
•	Manage online/offline status 
Each user should have:
•	Employee ID (Auto Generated) 
•	Full Name 
•	Profile Photo 
•	Mobile Number 
•	Email 
•	Department 
•	Designation 
•	Reporting Manager 
•	Username 
•	Password (Encrypted) 
•	Role 
•	Status (Active/Inactive) 
•	Two-Factor Authentication (Future Ready) 
•	Recording of working hours through login and logout

Login System
Every employee receives:
•	Username 
•	Password 
After login, they should only see the menus they have permission to access.
No employee should be able to access restricted URLs directly.
Protect all routes using middleware or permission checks.
